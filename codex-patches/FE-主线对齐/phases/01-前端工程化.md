# Phase 1 · React 前端工程化（不接后端，先原样跑起来）

> 目标：`frontend-react/` 成为可 build、可开发的正式工程，行为与 `design/index.html` 逐像素一致。
> 本 Phase **不接任何后端 API**，localStorage 行为原样保留——先把地基打平，Phase 2 起逐 store 换血。

## 改动步骤

1. **建工程**：`npm create vite@latest frontend-react -- --template react`，React 18（与原型一致，勿升 19）。
2. **搬文件**：`design/` 下全部 `ws-*.jsx`、`ct-*.jsx`、`lf*-*.jsx`、`icons.jsx` 与全部 `*.css` 搬入 `frontend-react/src/`。`tweaks-panel.jsx` 只保留 `useTweaks`（localStorage 设置 hook）与面板容器的最小实现，宿主协议（postMessage）部分删除。
3. **模块化（机械改写，不改逻辑）**：
   - 每个文件头部 `/* global ... */` 注释 = 它的依赖清单，据此补 `import`；文件尾 `Object.assign(window, {...})` = 它的导出清单，改为 `export`。
   - 过渡期保留 `window.*` 赋值一行（部分文件用 `window.WsWorks` 动态探测），Phase 8 统一清除。
   - CSS 按 `design/index.html` 的 `<link>` 顺序在入口 `main.jsx` 依序 import（顺序有层叠语义，不许重排）。
4. **字体**：Manrope + Noto Serif SC + JetBrains Mono；照搬 Google Fonts 引法或自托管到 `public/fonts`。
5. **路由**：保留原型 hash 路由（`#home` 等）与别名 `deepdesk→writer`（见 `ws-app.jsx` 的 `WS_VIEW_ALIAS`），不引入 react-router。
6. **生命周期接入**：`start-dev.cmd` / `stop-dev.cmd` / `scripts/dev.ps1` 增加 React 前端（端口 5174），与 Vue（5173）并行；README 注明两个入口。

## 不许做

- 不重命名文件、不「顺手重构」组件、不改样式；diff 应只包含 import/export 化与入口装配。
- 不删 `WsDemoTag`；不动 Vue `frontend/`。

## 自检

- `npm run build` 零警告级错误；dev 模式下与 `design/index.html`（静态服务器直开）肉眼对比：主页/构思/写作/待办/资料/编排/起草台/成稿/控制塔/设置/回收站逐屏一致。
- 主题切换、⌘K、新建作品、作品切换、回收站恢复（仍 localStorage）全部可用。
- 提交：`FE-ALIGN Phase 1: react frontend scaffold`。
