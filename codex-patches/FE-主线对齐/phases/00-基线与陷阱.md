## 0.2 Phase 1 机械转换陷阱（逐条核对）

| # | 陷阱 | 处理 |
|---|---|---|
| T1 | 所有 `<script src="xx.jsx?v=N">` / `<link href="xx.css?v=N">` 带**缓存查询串** | 搬入 Vite 后全部剥掉 `?v=N`；漏剥会导致模块解析失败 |
| T2 | CSS **层叠顺序有语义**（styles → screens → wr-redesign → wr-desk → ws-shell → ws-library → ws-author → ws-review → ct → ws-deep → lf2 → lf2-parts → lf3 → lf6） | 在 `main.jsx` 按 `design/index.html` 的 `<link>` 顺序 import，禁止重排或合并 |
| T3 | JSX 同样有**加载顺序**（icons → tweaks-panel → works → … → ws-app，前者在 window 上注册供后者用） | import 图按原 `<script>` 顺序建立；`ws-app.jsx` 是终端入口 |
| T4 | `ws-app.jsx` 底部有 `ReactDOM.createRoot(...).render(<App />)` | 移到 `main.jsx`；**不要包 `<React.StrictMode>`**（store 是模块级单例 + 副作用订阅，StrictMode 双挂载会暴露非幂等订阅，保真优先，留到 Phase 8 再治理） |
| T5 | `index.html` 有 splash 占位 `<div class="ws-splash">…</div>` 和 CDN 钉版 React/Babel 脚本 | splash 保留（体验细节）；CDN 脚本删除，React 改 npm 依赖 18.3.1 |
| T6 | `ws-app.jsx` 的 `WS_DEFAULTS` 外包着 `/*EDITMODE-BEGIN*/ … /*EDITMODE-END*/` 注释标记 | 这是设计工具的标记，删注释保留对象字面量 |
| T7 | `tweaks-panel.jsx` 含宿主 postMessage 协议（`__activate_edit_mode` 等） | 只保留 `useTweaks`（localStorage hook）+ 面板 UI；`ws-app.jsx` 里两处 `window.postMessage({type:"__activate_edit_mode"})`（调节舒适度按钮、⌘K 命令）改为直接开关本地设置抽屉 |
| T8 | 多处**运行时探测** `window.WsWorks && …`、`window.rvPush`、`typeof ARR_CHAPTERS !== "undefined"`（try/catch 包裹） | 模块化后改为静态 import；保留 try/catch 行为语义（探测失败走 fallback）直到 Phase 8 清理 |
| T9 | 视图元素带 `data-screen-label` / 可能残留 `data-comment-anchor` 属性 | 设计工具痕迹，无害，保留（删了会扩大 diff） |
| T10 | 字体走 Google Fonts CDN | 离线/内网环境自托管到 `public/fonts`，否则照搬 link |
| T11 | localStorage 键**无前缀**（`ws_works_created_v1` 等），与同源其它应用可能冲突 | Phase 1 原样保留（迁移逻辑要读旧键）；业务键随 Phase 2-7 消亡，UI 偏好键 Phase 8 统一加 `nv:` 前缀 |
| T12 | `design/` 里**不要搬**的文件：`tweaks-panel.jsx`（仅取 useTweaks）、任何 `merge-plan-*`、`design-canvas.jsx`（若混入）、`*-standalone.jsx` | 搬运清单以 `design/index.html` 实际引用为准 |
| T13 | esbuild 对 Babel standalone 语法的兼容 | 原型未用 Babel 专有特性，esbuild 直接可编；如遇报错优先怀疑 T1/T3 |
