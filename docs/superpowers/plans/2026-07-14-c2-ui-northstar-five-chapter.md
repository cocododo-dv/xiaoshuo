# C2：五章 UI 北极星闭环实施计划

> 状态：精简收尾；1×1 最小真实 UI 链已完成，完整 5×3 门保持开放
> 目标：从空白项目经真实 React UI 完成 5 章 × 3 场，六阶段均由浏览器交互触发；API 只复核终态、哈希和恢复一致性。

## 约束

- 不通过 `page.evaluate(fetch(...))`、Node `apiPost` 或硬编码 lane 冒充 UI。
- 只有“真实 locator 操作 + 浏览器发出预期请求 + 成功响应”三者同时存在，阶段才可记录为 `ui`。
- 项目必须由“新建作品”对话框创建，运行从空目录、空雪花工作台开始。
- 雪花结构化导入是作者功能：输入十步规范草稿，按依赖顺序保存并批准；不是 QA 专用按钮。
- 场景执行、候选终选、归档必须逐场通过起草台按钮完成；至少三场进入匿名候选终选。
- 章节聚合必须由成稿中心按钮触发；API 只读取聚合结果。
- 清空浏览器缓存并重启后端后，必须重新从后端恢复目录、正文、候选选择和章节聚合，哈希不变。
- 真实模型或质量门失败不得伪造通过；保留失败证据并修复可修工程问题。
