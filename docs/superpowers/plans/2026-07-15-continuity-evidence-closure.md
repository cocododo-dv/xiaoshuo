# AI 小说系统剩余修复与质量证据闭环计划

> 状态：工程闭环完成；真实质量证据待外部执行
> 前置结论：权威正文链 `0068/0069` 已通过定向验收；本计划处理其余连续性盲区、历史数据完整性和“真的更好”证据门。

## 1. 目标与边界

本轮必须同时回答两个不同问题：

1. **系统是否正确**：跨章节位置不能再退化为章节内 `scene_seq`；历史孤儿必须可取证、可回滚地处置；全量回归要形成完整结果。
2. **系统是否真的更好**：生成策略只能由未泄题、可复算、具真人 provenance 的盲评证据放行；模型自评、合成投票和模拟耐久只能验证工具，不能冒充真实效果。

没有真实模型凭据或真人投票时，本轮可以完成工程闭环和拒绝伪证据的门禁，但不得把真实五章、三十章耐久或真人偏好标成通过。

## 2. 修复方案

### A. 清除剩余跨章位置盲区

- `foreshadow_lifecycle` 项目健康统计以动态叙事位置计算已过场景和逾期，不再比较跨章局部序号。
- `scene_execution` 逆向因果骨架按章节目录顺序和场景顺序寻找前置场景。
- 测试覆盖重复 `scene_seq`、目录重排、空 `display_order` 和无效引用 fail-closed。

### B. 历史孤儿数据治理

- 新增默认 dry-run 的盘点/修复工具，至少覆盖 `llm_call_attempts -> llm_calls` 与 `snowflake_revision_links` 的缺失父级。
- apply 前必须生成逐行证据导出、数据库备份和 SHA-256；不得伪造父记录。
- 处置采用隔离/检疫语义，保留来源表、主键、原始负载、发现时间、原因和批次号；同一批次可幂等复算。
- apply 后执行 SQLite integrity、foreign key check、严格 database preflight 和核心正文指针核对；失败则回滚。

### C. 隐藏评测与防泄题

- 评测用例拆成“生成可见输入”和“评审私有标准”；生成器接口永远拿不到私有 rubric、参考答案、treatment 映射或评分阈值。
- 冻结题包记录 manifest hash、数据来源、隔离方式、题材与场景功能；冻结后任何文本、标签或 rubric 变化都使证据失效。
- 合成/模型评审仅可诊断，只有冻结的真人盲评、互异快照和完整 reviewer provenance 才能改变生产策略。

### D. 题材与场景功能策略

- 质量报告同时按 `genre` 与 `scene_function` 分层，避免用悬疑反转标准评价抒情过渡场。
- 策略选择必须有显式 fallback；样本不足的分层保持默认关闭，不从全局均值外推。
- Best-of-N 初始和迁移默认均为关闭；只有达到最小非平局样本、显著性、效果量、成本和独立复验门才可启用。

### E. 用户价值与运行指标

每个真实样本至少记录：

- 作者初稿到最终采用稿的规范化修改距离及修改比例；
- 首次生成是否可直接采用、最终是否采用及尝试次数；
- token、估算/实际成本、端到端延迟；
- 真人盲评选择、追读意愿和评审耗时。

报告必须给出有效分母、缺失率和分层结果，禁止把缺失值当成 0 或成功。

### F. 五章与三十章门

- **五章闭环**：5 章 × 3 场，15/15 非空权威归档、5/5 聚合、至少 3 次候选选择、Q0/Q1=0、来源泄漏=0；清缓存并重启后内容/选择/聚合哈希一致。
- **三十章耐久**：30 章全部归档，在第 5/10/20/30 章真实重启并核对状态哈希；每五章记录数据库体积、连续性、伏笔债、声音漂移、跨章重复、token/成本/延迟。
- 合成报告必须被真实证据门拒绝；真实运行若缺模型凭据、费用授权或真人投票，记录为外部阻断而不是通过。

## 3. 验收矩阵

1. 跨章定向测试及相关叙事回归通过。
2. 孤儿治理 dry-run 输出稳定；副本 apply 后孤儿为 0；线上 apply 前后有备份、导出、哈希和回滚演练。
3. 隐藏 rubric/答案无法从生成输入、盲评 ballot、普通 API 响应或日志中读取。
4. 篡改冻结题包、题材、场景功能或 rubric 后，报告不具备策略放行资格。
5. 合成投票、模型自评、匿名票、重复快照、样本不足和未独立复验均不能开启 Best-of-N 默认。
6. 指标报告正确处理空样本、缺失值、相同文本、中文文本和多次尝试。
7. 五章与三十章判定器通过离线极性测试；真实证据状态单独记录。
8. 后端全量、前端全量与生产构建形成完整退出码；任何超时都保留为未完成。

## 4. 放行规则

- **工程完成**：代码、迁移/工具、离线极性测试、定向和全量回归通过。
- **真实质量完成**：另需真实五章、真实三十章、冻结真人盲评和指标门全部通过。
- 工程完成不自动推导真实质量完成；Best-of-N 在真实质量完成前保持默认关闭。
